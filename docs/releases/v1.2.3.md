# Session Grove v1.2.3

This update protects chosen client titles, fixes recurring local Update failures and improves access through forwarded ports.

- **Keep names you already chose.** Explicit Codex transcription names are protected from the first import, including names set before Grove discovered the session. Automatic naming rechecks ownership before writing back, so manual choices take priority over pending results. Logical Session and node names remain independent.
- **Recover local Update safely.** Grove can reconnect a missing device baseline when the complete native history proves it extends the surviving saved history. Deleted shared-context placeholders are no longer scanned as live sessions. Different histories remain preserved with a specific error.
- **See the actual Update failure.** Failed updates identify the affected record and underlying error instead of displaying a generic session-compatibility message.
- **Use forwarded addresses.** Access through localhost, forwarded domains and forwarded ports keeps the address you opened. Existing access-token checks remain in place.
- **Respect service SSH configuration.** Git inherits custom SSH commands and executables rather than replacing them. Sync still authenticates on the machine running Grove, using the service account's SSH access; browser port forwarding does not forward Git credentials.
