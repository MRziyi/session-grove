# Session Grove v1.2.1

This release makes large conversation trees easier to explore and keeps everyday organization responsive.

- **Find a message across the whole tree.** Search from the detail header, see which transcription contains each result, and jump directly to its message.
- **Keep ancestors in view.** Offscreen ancestors appear individually along the opposite graph edge, with connected cards and scrolling for long chains.
- **Name active sessions together.** Preview a shared `[prefix]` for active client session titles. Applying another prefix replaces the previous one; logical Session and node names remain independent.
- **Clearer project browsing.** Rounded project containers, compact disclosure controls, centered Older projects tags and content-sized navigation make groups easier to scan. Trash stays at the bottom, and expanding older projects preserves your reading position.
- **Readable transcripts.** User messages stay on the right, agent replies on the left, with aligned selection checkboxes on the right. Tree-wide counts and transcription context estimates now sit at their corresponding header levels.
- **Responsive Trash.** Removing a path keeps the surviving tree open. Retained-history cleanup runs in a background worker, checks for concurrent changes before reclaiming records, and shows its phases in the progress card.
- **Safer Discard.** Revert Grove organization without rewinding messages, removing new branches or deactivating client sessions. Discarded automatic organization waits for an explicit Continue action.
- **Less background work.** Never-uploaded trees no longer require full history hashing to appear pending. Unchanged ancestor overlays avoid repeated DOM writes, and closing a tree releases their nodes and handlers.

The release also preserves message identities through opaque compaction recovery and consolidates maintenance documentation. Workflow help remains in **ⓘ Information**.
