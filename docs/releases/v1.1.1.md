# Session Grove 1.1.1

Double-click a project, session or node title to edit it in place. A subtle hover border hints at the interaction. The check mark or Enter saves; clicking elsewhere or pressing Escape cancels. The same component works in project navigation, project categories, session rows, graph nodes and transcript captions. Existing Rename controls open that editor, and stale edits are rejected.

Session names now belong to the whole tree, independently of per-path transcription titles. Automatic Session names follow the first named node; manual names stay fixed. Missing naming records are backfilled, and automatic node names are reconsidered when a fork changes the covered range.

A separate **Update transcription titles on new nodes** switch is off by default. Compatible Codex VS Code clients receive synchronized titles through the official rename API and live list refresh. New nodes, including fork/compaction boundaries, trigger naming from completed-node user requests and concise assistant results. Tail edits do not trigger it, identical evidence reuses a result, and enabling the option does not bulk-rename existing paths. Unsupported clients/platforms cannot enable it.

Source uses inline original/automatic title fields and one compact **Capture changes** list, with change type before time. Editable names show a hover border and text cursor without a tooltip.

Node titles use the full card width, with tool icons overlaid. Compaction boundaries now name completed nodes on standalone paths as well as trees. Settings removes redundant static hints and keeps startup errors beside its status. Windows startup tolerates slower PowerShell initialization and restores the previous shortcut when verification fails.

Settings now has a one-click **Start automatically at login** switch for macOS and Windows. It changes the next login without stopping the running service and is unavailable in demo mode. Failed setup retains the prior configuration.

Both READMEs explain the default-off Settings switch and its Enabled/Disabled/Updating/Failed states. Grove configures the user-level startup entry directly, without terminal setup.

Background organization and Update preserve your reading position. Unrelated changes leave the current transcript in place; changes in the current tree retain the visible message, selection and graph camera.

Validation includes the full regression suite, four browser suites and a real-library snapshot run covering inline save/cancel, stale edits, name coverage and preservation of conversation content and project membership. See [the validation record](../1.1.1-validation.md).
