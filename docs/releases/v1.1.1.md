# Session Grove 1.1.1

Double-click a project, session or node title to edit it in place. A subtle hover border hints at the interaction. The check mark or Enter saves; clicking elsewhere or pressing Escape cancels. The same component works in project navigation, project categories, session rows, graph nodes and transcript captions. Existing Rename controls open that editor, and stale edits are rejected.

Smart organization now records one model naming result for every eligible normal session, including already-filed sessions and forks. A branch is named from its own first exchange. Manual names are preserved. Automatically named nodes retain the range used for naming and are reconsidered when a later fork changes that range, preventing a later topic's title from persisting on an earlier shared prefix.

Source now looks like a button and explains its fields. Recorded client applications appear when available; absent client metadata is explained instead of displaying an unexplained `unknown`. Original client titles and the model's naming result remain visible there, while session selectors show the Grove name.

Settings now has a one-click **Start automatically at login** switch for macOS and Windows. It changes the next login without stopping the running service and is unavailable in demo mode. Failed setup retains the prior configuration.

Both READMEs explain the default-off Settings switch and its Enabled/Disabled/Updating/Failed states. Grove configures the user-level startup entry directly, without terminal setup.

Validation includes the full regression suite, four browser suites and a real-library snapshot run covering inline save/cancel, stale edits, name coverage and preservation of conversation content and project membership. See [the validation record](../1.1.1-validation.md).
