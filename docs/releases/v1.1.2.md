# Session Grove 1.1.2

Pending uploads stays open while the pointer is over the banner or panel, including the space between them. Re-entry shares pending reads, loading/error states use the same layout, and changed upload contents refresh without replacing them with a loading flash.

Double-click or F2 is the single rename interaction. Editors align with their original text and single-click navigation waits 200 ms instead of 320 ms. Settings now uses the shared accessible dropdown for every select, including context windows and request concurrency.

Graph compaction controls remain visible across path selection and update the path they belong to. Native transcription titles appear in muted, truncated text below endpoint nodes. Source adds compact working-directory, transcript-file and native-session-ID fields.

Client-side manual renames are imported on Update and retained as manual transcription titles. Whole-tree Session names stay independent.

Validation covers the full regression suite and four browser suites, including banner-to-panel travel, no duplicate hover reads, editor alignment, Settings dropdown saves, cross-path compaction controls and native title roundtrip without transcript-body changes.
