# Session Grove 1.1.7

Opening `localhost:7421` now redirects to `127.0.0.1:7421` instead of showing a JSON access error. API address and cross-origin protections remain in place.

Recover automatically when initial page requests fail or the local connection is interrupted. Initialize connection controls before rendering errors, retry startup, limit read waits and prevent overlapping status polls. Returning online or to the tab checks the service again.

Node renaming reuses lightweight inputs from the current tree instead of reparsing unchanged history. Revision changes and transaction rollbacks invalidate these inputs, and only one tree is retained.

Double-click transcription titles in the graph header or below endpoint nodes to rename them with the existing inline editor. Manual titles synchronize through the compatible running Codex VS Code client, remain independent of the Session name, and show progress or a retained error. Failed synchronization rolls back the native title; concurrent edits are checked before applying results.

Normal `pnpm start` / `npm start` runs in the background so closing Terminal does not stop the service. Development mode remains in the foreground.

Regression coverage includes failed initialization, offline/online recovery, terminal-independent startup, rename cache invalidation, manual title synchronization and rollback, and browser editing. Release publication requires the macOS, Linux and Windows CI groups to pass.
