# Session Grove 1.1.3

Large session trees now show loading immediately in the lower-right task panel. Reading history, processing paths, building the tree and preparing the display are visible stages. Tree construction yields between paths so navigation and service requests can continue. Switching away cancels an obsolete open; errors remain visible until dismissed.

Compaction controls sit on their actual connections, with reserved space that keeps them off nodes and endpoint titles. Rewritten copies of the same shared compaction no longer create a column of duplicate switches. Compaction identity now uses the complete payload and occurrence order, independent of copied timestamps and ordinals. A shared control explicitly shows its affected path count and updates all matching live paths in one transaction. Different recorded results split subsequent context even when visible messages match; consecutive compactions on one path remain separate. Existing per-copy choices are retained and shown as Mixed until an explicit shared decision. Old timestamp-based IDs remain readable aliases. The redundant context-choice tooltip is removed.

Background organization skips unchanged transcription trees. Family matching rejects unrelated working directories before parsing their histories. Sync status hashes large graphs incrementally and releases temporary graph caches, and unchanged entity writes no longer modify SQLite or invalidate views. Explicitly aborted Codex turns can be deactivated without treating them as completed fork checkpoints.

Validation: 303 regression tests pass, with two environment-dependent tests skipped. Browser acceptance covers session trees, sync, drag/move, inline editing, shared compaction control and legacy mixed-state migration, loading feedback and cancellation. The local resource benchmark uses a disposable backup and leaves the source library untouched:

```sh
pnpm bench:local --library /path/to/.session-grove
```

Resource measurements use CPU time, memory and I/O as proxies; they do not claim measured electrical energy. Large uncached histories can still take time to load, now with visible progress.

Use Grove 1.1.3 or later on devices that edit these context policies; older Grove releases do not understand the new stable IDs. Native transcript formats and bytes are unchanged.
