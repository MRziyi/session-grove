# Session Grove v1.1.8

This update makes selecting conversations easier, reduces the wait when moving sessions to Trash, and keeps automatic naming moving when a conversation changes.

- Click a message card to select its whole turn, including multiple user inputs and assistant replies. Settings also offers individual-message and start/end selection.
- Selecting across a gap includes the messages in between. Deselecting an interior message or turn keeps the preceding continuous selection. A colored count tag beside **Transcripts** clears the selection in one click.
- Current graph paths use thin outlines without a gap. Recorded context appears in a compact rounded card with balanced spacing.
- Automatic transcription naming recovers from changed paths and removes archived jobs from its waiting queue, reusing completed naming results where possible.
- Moving sessions to Trash avoids duplicate cleanup and keeps valid session summaries cached. In an isolated real-library comparison, the deletion request dropped from 5.01 to 1.86 seconds; native-client file operations were excluded from both measurements.
- The English and Chinese READMEs now focus on what Grove does and how to get started. In-app **ⓘ Information** remains the entry point for workflow help.

Validation includes the full regression suite, browser interaction checks, and isolated checks using a real library.
