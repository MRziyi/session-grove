Session Grove 1.0.1 improves project organization, settings and recovery from accidental local edits.

- Drag one session or a selected group into another project. Lists scroll while dragging near their edges, and empty sidebar projects accept drops.
- Older projects now follows the same threshold as Project contents: a project becomes older when all of its sessions would be folded. Expanding Older projects shows the sessions immediately.
- Pending uploads has checkboxes and a Discard changes menu. It restores the last acknowledged version, removes never-synced additions, and keeps a recovery copy in Trash. Changed active conversations must be deactivated first; metadata-only changes can be reverted while active.
- Git verification checks emptiness, top-level structure and the Grove marker without downloading transcript bodies or history. Nonempty repositories require filtering support; verification does not silently fall back to a full download.
- Settings saves changes automatically. Verification buttons sit beside their inputs, errors sit below them, and context windows use descending presets and explicit defaults. A successfully verified API key enables classification and node naming.
- Deactivating an unused activation endpoint removes its empty graph placeholder. Continuations with chats and deliberate forks remain available. The sidebar footer no longer has extra bottom spacing.
- Previous archives stays local. Archived-only content is excluded from new uploads; shared prefixes required by active branches remain. Push removes old archive entries from the current Git tree, while prior Git commits and local archives remain intact. Upgrade all devices to prevent older clients from republishing archived sessions.
- Compatible Codex VS Code extensions receive best-effort local cache notifications after successful activation/deactivation. Both tools have Open in VS Code links; Claude uses its official session URI handler and requires the matching workspace. Automatic external Claude list refresh and online deactivation are not implemented. Codex notifications use an inspected private protocol and are currently supported on Unix hosts only.

The release workflow runs unit/integration tests on Linux, macOS and Windows and browser regressions on Windows before publishing this release. Local browser coverage also exercises pending selection/discard, drag scrolling, expanded older projects, automatic settings and footer alignment. No real native conversation is changed by those fixtures.
