# Session Grove v1.1.10

This update fixes interrupted Git imports, keeps automatic organization from making old conversations appear recently edited, and makes large project lists easier to browse.

- **Reliable imports:** JSONL records containing Unicode line or paragraph separators now load intact. Compressed native histories retain their identity and full context through discovery, archive and recovery.
- **Choose your dates:** Settings offers recent conversation, include manual edits (default), and include automatic organization. Sync keeps its own full modification clock.
- **Fold project categories:** Click the arrow or category to collapse/expand. Double-click the name to rename. Open and collapsed categories accept session drops and show the green target outline.
- **Respect completed organization:** Existing session titles and older naming records are preserved on a new device. Smart Organization waits for sync to reconcile incoming metadata before validating pending work.
- **Cleaner Information:** Remove the stray closing brace after Tokens and tools.
- **Faster Windows checks:** Private writes use native ACL setup before writing secret bytes; CI caches pnpm dependencies and splits browser work. Browser reload and unsafe random-port test races are corrected.
- **Git-only sync:** Remove the retired WebDAV backend, settings, migration scripts and provider tests. Git history, local recovery and native activation remain covered. Existing legacy files on disk are neither read nor deleted.

The release also includes the pending project-directory and compressed-history fixes since 1.1.9. Empty projects remain hidden during ordinary browsing and appear as drag destinations.

Validation uses the full unit/Git suite, eight isolated browser flows, and Windows/macOS/Linux CI. The Unicode import fix was additionally checked read-only against the affected local cache: all 13,928 records matched whole-file parsing.
