# Session Grove 1.1.6

Compaction controls now belong to individual directed edges. A fan-out has separate controls on the affected branches, and changing one edge leaves other outgoing edges unchanged. Genuine successive compactions use explicit context-only points so each edge has at most one switch. Older user-only fork snapshots that are immediately completed by the same boundary's encrypted result receive a narrowly matched compatibility treatment: On uses the final recorded state; Off bypasses that boundary without falling back to the incomplete snapshot. Original history bytes remain intact.

The selected transcription stays highlighted across nodes, connectors, compaction controls and its endpoint. Switching paths automatically frames the route or its readable endpoint region; Fit path restores that view after panning. Background updates preserve the user's camera and reading position. Fan-out junctions no longer overprint many curves in a narrow band.

Smart organization recognizes both current and older IDE request headings. It backfills previously skipped closed nodes, including single-child segments, while preserving manual names and changing tails.

This release also includes the previously committed conflict-resolution panel: affected items, previous/current differences, explicit choices, stale-review protection and return to pending uploads. Disposable Git test repositories disable background maintenance to avoid cleanup races.

Resource checks found no material backend slowdown in the measured local-library workload. The browser now releases transcript/layout references and handlers when returning to the list. A synthetic 16-path workload reduced post-close retained JS heap from roughly 7.9 MiB to 1.5 MiB; path-switch synchronous work remained around 2–3 ms. Group-level flags are computed once rather than repeatedly for every inherited copy. Reproduce the measurements with `pnpm bench:local --library PATH` and `pnpm bench:ui`. Measurements are workload-specific CPU/heap/I/O proxies, not electrical power measurements.

Validation: 323 regression tests passed locally, two platform-dependent tests were skipped, and seven browser suites cover the existing workflows and new controls. Publishing requires all macOS, Linux and Windows CI groups to pass. Devices editing a shared library should run the same current version for consistent edge-control semantics.
