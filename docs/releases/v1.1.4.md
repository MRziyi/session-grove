# Session Grove 1.1.4

Fix a concurrent-update race in session loading: an obsolete tree can no longer re-enter the cache after the library changes. Packed responses also avoid caching an invalidated graph.

Deep conversation trees now use iterative layout instead of recursive calls, avoiding stack overflow. Depth spacing uses a single index instead of repeatedly scanning all nodes; existing layout geometry is preserved.

Windows CI runs core, native startup, Git and browser checks on separate runners. Git cases are split into two complete groups, retaining every assertion and the existing timeouts. Per-file timing summaries and artifacts make slow or failing checks easier to diagnose.

Validation: 306 tests passed locally, with two Windows-only tests skipped; all five browser suites passed. Read-only library-copy checks verified sync fingerprint equivalence and layout equivalence across the largest trees. Publishing requires all macOS, Linux and Windows CI groups to pass.
