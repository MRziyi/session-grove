# Session Grove 1.1.5

New libraries open with a short guide and an Update button to find local sessions. After an empty-library scan, Projects shows sessions from either client. Empty scan results, categories and searches explain what to do next, and scanned folders are available on demand.

Pull and Push stay disabled until sync is configured. A sidebar shortcut opens Git settings, while unavailable upload indicators and panels stay hidden. Local use does not require Git sync or an OpenAI API key.

The sidebar keeps its compact ⓘ Information icon, with the guide inside. Both READMEs now explain the first-use workflow and the difference between sessions, transcription paths, nodes and Pending labels.

Browser regressions cover empty-library startup, no-result scans, native-file discovery, English/Chinese, narrow-screen footer alignment, search recovery and configured/unconfigured sync. Publishing requires all macOS, Linux and Windows CI groups to pass.
