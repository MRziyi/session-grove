# Session Grove 1.1.0

Archive and Trash recovery now preserve shared conversation trees. Individual restored branches rejoin their surviving family, and older detached recoveries can be repaired when the saved recovery event and shared history prove the relationship. Restoration returns to the correct project and highlights the restored rows twice.

Pending uploads is narrower, keeps session/project titles together, places dates under checkboxes and keeps Select all / Deselect stationary. Current Active supports drag to project categories; Client archive and Trash use project categories too.

Recovery, activation, conversion, deactivation and Discard expose concrete phases in the lower-right task panel. Recovery avoids a full-library cleanup, and native operations avoid rewriting every session baseline. Unused intermediate-node continuations remain reactivatable after official Codex settings updates.

Validation used a consistent snapshot of an actual 226-record, 19-project local library: all 73 visible trees, including a 42-path family, plus the installed official Codex client. No model turns were submitted. Private transcripts and screenshots are excluded from this release. Detailed coverage and measured limits are in [1.1 validation](../1.1-validation.md).

Native baseline storage is migrated lazily on writes. Keep the pre-upgrade library backup if downgrading to 1.0.x; the older version does not understand the new baseline references. Claude serialization/conversion is tested, but a Claude VS Code extension was not installed on the acceptance machine and its interactive UI was not exercised.
