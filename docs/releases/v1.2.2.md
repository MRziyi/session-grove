# Session Grove v1.2.2

This release reduces library storage overhead, makes maintenance easier to find, and improves sync review and Source responsiveness.

- **Storage controls in Settings.** See local space usage, optimize an existing library without losing history, and preview cleanup of unused files and older maintenance backups. Cleanup creates and verifies a current recovery point before removing older copies.
- **One place for attention and progress.** Storage maintenance now uses the top status area. Select storage or Smart Organization attention to open Settings at the relevant card, which flashes twice.
- **A faster, tree-wide Source view.** Source summarizes the entire Session tree, including its latest capture time, working directories and client files. It reads metadata rather than parsing every transcript and historical revision. Repetitive capture-change rows are removed; underlying history stays intact.
- **Clearer sync conflicts.** Equivalent empty context policies and equivalent node groupings no longer require a choice. Real node changes show affected messages and ranges. Reviewing pending changes releases temporary expanded history graphs instead of retaining them in memory.
- **More compact settings and help.** Core configuration appears first; small local preferences share a compact card. Information disclosure headers respond across the full card and have clearer triangle spacing.
- **Windows Git compatibility.** Content-addressed graph and media paths work with Git long-path support without requiring global Git configuration changes.

Large Git metadata is split into verified parts, repeated embedded payloads are stored once per tree, and local history uses lossless compact storage. Existing single-file repositories remain readable, and Git history is preserved.

**Update Grove on every device before syncing the optimized repository format.** Older releases cannot read the new compact format. Storage optimization starts when you choose it; updating does not automatically delete recovery backups or rewrite remote history.
