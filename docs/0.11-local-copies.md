# 0.11：本地副本、同步时机与浏览行为

## 同步规则

| 操作 | 本机行为 | 远端行为 |
| --- | --- | --- |
| 打开页面、切换项目、窗口重新获得焦点 | 使用已保存的目录 | 无请求 |
| 搜索 | 搜索目录标题及已下载正文 | 不为搜索下载正文 |
| 打开已有本地副本的会话 | 读取本机资料库 | 无请求 |
| 首次打开带云图标的会话 | 校验后完整保存该树；以后可离线浏览 | 按需下载这棵树 |
| 点击 Sync | 更新目录；合并已下载树的远端版本；发布本地变更 | Pull → Push；未打开的云端树仍不下载正文 |
| 本机原生会话或整理发生变化 | 开启一次上传倒计时，默认 15 分钟 | 到时只上传有变化的树 |
| 本机没有变化 | 不设上传计时器 | 不产生定时上传请求 |
| Update | 扫描本机 Codex / Claude 文件 | 无请求 |

云图标只表示本机没有会话正文，不表示备份状态。没有图标的本地记录也可能尚未上传；顶部的本地改动、上传进度、失败提示负责说明同步状态。下载完成后副本持久保存在 SQLite 中，重启不会丢失，也不会自动清理。下载会话不会下载其工作目录中的项目文件，也不会自动 Activate。

自动 Push 必须检查远端版本以避免覆盖并发修改；这一步可合并正在上传的同一棵树。它不会刷新浏览目录或下载其他会话。浏览目录快照只在显式 Sync 时更新。并发冲突仍需解决后才能发布。断网时已有本地副本继续可读；云端独有会话下载失败会明确报错，不展示部分历史。

设置中的自动上传间隔从首次检测到本地变化开始；重复扫描和状态查询不重置倒计时。关闭自动上传后不会通过另一个短计时器偷偷上传。大批传输仍先暂停供用户确认；已校验的批次可续传。

这个按需下载的基础语义与 [OneDrive Files On-Demand](https://support.microsoft.com/en-US/onedrive/save-disk-space-with-onedrive-files-on-demand-for-windows) 和 [Dropbox online-only](https://help.dropbox.com/sync/make-files-online-only) 一致：打开云端独有文件后变成本地可用。Grove 依照本项目的需求，采用显式 Pull，而不是这些服务的持续远端推送。

## 界面与上下文

- Sync 使用双箭头圆环；Update 保持单箭头。
- 大树首次打开适配完整图，而不是对准排序第一条孤立路径。Focus 使用节点 ID，并把对应节点放到可读比例的中心；它不重建 transcript。
- 勾选 transcript 只修改 checkbox、选中样式和工具栏，保留滚动位置及展开的工具记录。
- 最近没有对话活动的项目统一折叠在“较早的项目”父组内，左右两栏展开状态一致。默认 30 天，可选 7 / 15 / 30 / 60 天；这只是显示折叠，不是归档或删除。搜索可以找到折叠内容。
- “显示定时与后台会话”立即保存并读取本机新发现的后台记录。查看它们不会让整批后台历史加入自动上传；明确管理过的后台归档继续同步。
- Claude 原生自定义/自动标题优先；缺少标题时，从首条实际提问中去除已知 IDE 附加块与本地命令块，仅用于生成显示标题，不改原始记录。只有初始化信息、没有实际提问和有效助手回答的记录进入后台组，不能仅凭 XML 前缀判定为无用会话。
- Information 按主题默认折叠。Activate as 使用统一自定义选择器，打开即显示 Lean / Full 两种估算 token 数。

Lean 保留对话、工具调用、重要指令、写操作和错误；对长只读输出作截短，思考和传输元数据保留在源会话。Full 把原始 JSONL 原样作为历史档案装入目标上下文，不重放外来工具。两者都不会复制模型内部状态。估算是打包文本的启发式 token 数，不是精确计费；目标环境的指令、图像和文件读取会增加用量。源会话不变。

工作目录默认沿用源会话。迁移电脑后旧路径不存在，需要指定本机真实目录；服务端在 Activate 前验证。预览不会调用模型或写入原生 session。

## 验证

- `pnpm test`：包含多设备按需下载、持久缓存、显式更新、自动 Push 不刷新目录、空闲无计时器、后台显示不触发上传及 Claude 标题分类。
- `node scripts/ui-011-smoke.js`：隔离 Chrome（调试端口 9231）与临时 WebDAV，测试两种 token 预览、自定义选择器、设置持久化、左右折叠及完整 Sync。
- `node scripts/ui-011-real.js <tree-id> [tree-id...]`：可选的本机真实库只读验收；检查用户报告的两棵 Chrono 树，逐节点验证 Focus，并通过鼠标输入验证滚动稳定。报告与截图位于被 Git 忽略的 `test-results/`。

云端协议仍为 schema 5，与 0.10 兼容。本地摘要缓存升级到版本 5，会一次性重新计算旧摘要；原生 JSONL 不变。
