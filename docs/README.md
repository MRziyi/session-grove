# Project documentation

The [English README](../README.md) and [Chinese README](../README.zh-CN.md) introduce Grove to users. Control and workflow help is available through the application's **ⓘ Information** button.

These documents describe the current implementation and maintenance workflow:

- [Architecture](architecture.md): components, storage and invariants.
- [Operations](operations.md): service management, configuration and diagnostics.
- [Git sync](git-sync.md): repository format, reconciliation, Discard and recovery.
- [Context and native history](context.md): activation, compression, conversion and token estimates.
- [Smart Organization](smart-organization.md): evidence, triggers, ownership and paused work.
- [Testing](testing.md): regression commands, acceptance cases and real-library validation.
- [Icon credits](icon-credits.md).

[CHANGELOG](../CHANGELOG.md) collects unreleased work and version history. [Release notes](releases/) describe published versions. Historical design proposals and dated validation reports remain available in their original Git commits and release tags; they do not define current behavior.
